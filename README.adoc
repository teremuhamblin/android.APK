Ce projet a été conçu pour :

- Offrir une base Android immédiatement compilable

- Fournir une structure propre, claire et extensible  
- Servir de squelette pour tout futur projet Android

== 🔧 CI/CD — Dossier .github/workflows/

=== android.yml — Build Debug
- Ubuntu 24.04  
- JDK Temurin 17  
- Validation du wrapper Gradle  
- Build Debug  
- Upload app-debug.apk

=== android-release.yml — Build Release signé
- Signature via GitHub Secrets  
- Génération APK + AAB  
- Artefacts prêts pour Play Store  

Secrets requis :
[horizontal]
ANDROIDKEYSTORE, ANDROIDKEYSTOREPASSWORD, ANDROIDKEYALIAS, ANDROIDKEY_PASSWORD

=== android-publish.yml — Publication GitHub Releases
- Déclenché sur tag versionné  
- Build Release  
- Création automatique de release  
- Upload APK + AAB  

=== android-instrumented-tests.yml — Tests instrumentés
- Lancement d’un émulateur Android  
- Exécution des tests UI  
- Upload des rapports

== 🚀 Compilation locale

=== Build Debug
[source,bash]
----
./gradlew assembleDebug
----

APK généré dans :
[source,bash]
----
app/build/outputs/apk/debug/app-debug.apk
----

=== Build Release (non signé)
[source,bash]
----
./gradlew assembleRelease
----
